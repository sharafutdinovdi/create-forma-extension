# Security policy

Security fixes target the latest release of `create-forma-extension`.
Generated projects own their installed dependencies and updates after scaffolding.

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/sharafutdinovdi/create-forma-extension/security/advisories/new).
If private reporting is unavailable, open an issue requesting a private contact without exploit details or sensitive data.
Reports should identify the affected version, reproduction steps and impact.
Credentials and private Forma project data must be omitted from public issues.
